# QuickShulker 3.0.3

This release adds client-optional bundle screens for Fabric servers.

- Vanilla clients can join a QuickShulker server while bundle opening is enabled.
- Unmodded clients receive a server-side paged vanilla container.
- Modded clients retain the existing scrolling 64-slot bundle interface.
- The custom bundle `MenuType` registry entry has been removed.
- Enhanced bundle interactions use vanilla open-screen, slot-sync, click, drag, and close packets after the initial QuickShulker request.
- Builds are provided for Minecraft 26.2 and 26.1.

This repository is a fork of [MoRanpcy/quickshulker](https://github.com/MoRanpcy/quickshulker), based on the original [kyrptonaught/quickshulker](https://github.com/kyrptonaught/quickshulker).
