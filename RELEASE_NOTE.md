# QuickShulker 3.0.4

This maintenance release introduces a new, clean QuickShulker logo recreated as a maintainable SVG source.

- The box body's side edges now align exactly with the lid.
- The rendered PNG icon is included for Fabric and launcher compatibility.
- Public API signatures remain fully compatible with 3.0.3 and upstream integrations.
- Builds are provided for Minecraft 26.2.x and 26.1.x.

This repository is a fork of [MoRanpcy/quickshulker](https://github.com/MoRanpcy/quickshulker), based on the original [kyrptonaught/quickshulker](https://github.com/kyrptonaught/quickshulker).
